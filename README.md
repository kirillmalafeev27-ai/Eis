# Льдины — Die Eisschollen

Третья игра серии после «Сокровищницы» и «Шахты». Весна, на реке ледоход: каждый верный
ответ на вопрос по немецкому — прыжок на соседнюю льдину. Тонкий лёд трескается быстро,
толстый со снежной шапкой держит дольше, а река тает. На том берегу в избушке горит окно,
а по пути лежат три рыбы — за каждой нужно рискнуть.

Всё нарисовано в рантайме вырезанной бумагой (Canvas 2D → атлас → Phaser 4): вода из трёх
слоёв бумажных волн, льдины с кромкой и пеной, герой-перекладка «на двойках», слова-звуки
из цветных букв. Свет рассказывает, как разошёлся ледоход: ясный день → золотой час →
сиреневый закат, тени удлиняются, окно избушки разгорается. Звуки синтезируются (ZzFX),
аудиофайлов и внешней сети нет.

Источник истины по игре — [`PLAN.md`](PLAN.md), отклонения — в [`DECISIONS.md`](DECISIONS.md).

## Команды

```bash
npm install
npm run dev        # игра на http://localhost:5173
npm test           # правила, генератор, калибровка риска (Vitest)
npm run build      # проверка типов и сборка в dist/
npm run lint       # ESLint
npm run format     # Prettier
npm run sim -- --level 3 --runs 2000   # симуляция ботами: --tmed 5 --p 0.8 --bot greedy
npm run e2e        # сборка + Playwright: контраст, раунд, раскладка, клавиатура, звук
```

Полезные адреса в dev-сборке (или с `?test` в собранной):

- `?level=3` — сразу раунд уровня 3;
- `?scene=contrast&strength=0.5` — тестовая сцена контраста (8.4);
- `?nofilters` — запасной путь без фильтров (8.5);
- клавиша `` ` `` — отладочная панель (13.7): FPS, сид, таймеры, «заморозить таяние» и др.

## Управление

- **Касание / мышь**: ответ — фишка с вариантом; цель — тап по льдине или берегу;
  «К берегу» и «Стоять» — кнопки на плашке с корзиной.
- **Клавиатура**: `1`–`4` — ответ, стрелки — соседняя льдина, `Shift` + стрелка — длинный
  прыжок, `H` — к берегу, пробел — стоять, `P` / `Esc` — пауза.

## Встраивание

```ts
import { mountIce } from './src/embed';

const game = mountIce(document.getElementById('app')!, {
  questions: myProvider, // QuestionProvider: next(), report()
  // необязательно; по умолчанию localStorage с префиксом `ice:`
  storage: { get: (k) => sessionStorage.getItem(k), set: (k, v) => sessionStorage.setItem(k, v) },
  level: 1, // необязательно: сразу раунд, без меню
  onFinish: (r) => console.log(r.won, r.fish, r.stars, r.timeMs),
});
// game.destroy() освобождает канву, текстуры, AudioContext и слушатели.
```

## Устройство

- `src/core/` — чистая логика без Phaser: сетка, прыжки, риск, маршрутизатор, таяние,
  редуктор `reduce(state, action)`, генератор уровня и решатель. Детерминирована по сиду.
- `src/config/` — все числа (`balance.ts`, `levels.ts`) и цвета (`palette.ts`).
- `src/shared/` — общие модули серии: раскладка с темами, панель вопроса, темп, звук, бумажный кит.
- `src/art/` — процедурный арт вырезанной бумаги, `src/render/` — виды мира на Phaser 4.
- `src/scenes/` — загрузка (генерация арта) и сцена мира, которая умеет и заставку меню.
- `src/game/` — приложение: фазы, экраны, ввод, звук, сохранение; `Round` — раунд с журналом действий.
- `src/ui/` — DOM-интерфейс: плашка с корзиной, экраны (меню, уровни, пауза, настройки, итоги).
- `tools/sim.ts` — симуляция ботами (раздел 14), `tests/` — Vitest, `e2e/` — Playwright.
